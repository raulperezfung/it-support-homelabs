# IT Support Homelabs

This repository contains hands-on labs focused on practical IT Support and Windows systems administration skills, including Windows Server, Active Directory, Group Policy, user and group administration, permissions, domain workstations, and troubleshooting.

- Windows Server 2022
- Active Directory Domain Services
- DNS
- Organizational Units
- User and security group administration
- Windows domain join
- Group Policy
- Group Policy Preferences
- File sharing
- NTFS permissions
- Network drive mapping
- Basic troubleshooting
